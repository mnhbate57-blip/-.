# Сэтгэлийн шуудан: төлбөртэй мэндчилгээний вэб

Хэрэглэгч карт бичээд QPay-р төлнө. Төлбөр баталгаажмагц карт нээгдэж, хүлээн авагчид илгээх холбоос гарна. Төлбөрийн мөнгө таны QPay merchant дансанд орно. Картын мэдээлэл ба төлбөрийн төлөв серверт хадгалагдана, карт төлбөрөөс өмнө харагдахгүй.

## Яаж ажилладаг вэ

1. Хэрэглэгч карт бичээд "Төлбөр төлөх" дарна. Сервер картыг шалгаад QPay-д нэхэмжлэх үүсгэнэ.
2. Хэрэглэгч QR кодыг банкны аппаараа уншуулж төлнө.
3. QPay таны сервер рүү `/api/payments/callback` дуудна. Сервер callback-ийн агуулгад итгэхгүй, QPay-ээс "төлөгдсөн үү" гэж өөрөө асууна. Дүн таарвал захиалга `paid` болно.
4. Хуудас 3 секунд тутам төлөв шалгаж байгаа тул хэрэглэгч шууд карт, холбоос харна.

## Нэг удаа хийх тохируулга

1. QPay-тэй merchant гэрээ хийж, дараах 3 зүйлийг авна: username, password, invoice code. Туршилтын (sandbox) эрх эхлээд авбал сайн.
2. Node.js 18 эсвэл түүнээс дээш хувилбартай сервер хэрэгтэй. Render, Railway, Fly.io, VPS гэх мэт аль ч байдаг. `https` хаягтай домэйн заавал хэрэгтэй, QPay callback дуудна.
3. Орчны хувьсагчдыг `.env.example`-ийн дагуу хостинг дээрээ тохируулна:
   - `PAYMENT_PROVIDER=qpay`
   - `BASE_URL=https://таны-домэйн.mn`
   - `QPAY_BASE_URL`, `QPAY_USERNAME`, `QPAY_PASSWORD`, `QPAY_INVOICE_CODE`
   - `CARD_PRICE_MNT=3000` (картын үнэ)
   - `ADMIN_KEY` (урт санамсаргүй тэмдэгт мөр)
   - `NODE_ENV=production`
   - Reverse proxy ард ажиллаж байвал `TRUST_PROXY=1`
   - `DATA_FILE`-ийг сервер дахин асахад устдаггүй дискэн дээр заана
4. `npm start` гэж ажиллуулна. Нэмэлт сан суулгах шаардлагагүй.

## Нэг дарж асаах

- Windows: `start.bat` дээр давхар дарна.
- Mac: `start.command` дээр давхар дарна (эхний удаад хаах үед зөвшөөрөл асууж магадгүй). Linux: `./start.sh`.
- Хөтөч автоматаар нээгдэнэ. `.env` файл (`.env.example`-ийг хуулж нэрийг нь `.env` болгоод утгуудыг бөглөнө) байвал түүнийг уншина, байхгүй бол туршилтын горимд ажиллана. Node.js суугаагүй бол санууллаа өгнө.
- Энэ нь таны компьютер дээр ажиллуулах хэлбэр. Хэрэглэгчид төлөхийн тулд сервер, домэйн хэрэгтэй хэвээр.

## Эхлээд туршиж үзэх

- Түлхүүргүйгээр: `npm start` (PAYMENT_PROVIDER-ийг тохируулаагүй бол mock). "Туршилтын төлбөр хийх" товч гарна. Жинхэнэ мөнгө хөдөлдөггүй.
- Автомат шалгалт: `npm test` (27 шалгалт, зураг оруулсан).
- QPay sandbox: `QPAY_BASE_URL=https://merchant-sandbox.qpay.mn/v2` болгож, жижиг дүнтэй захиалга үүсгэн төлж үзнэ. Callback ирэх эсэхийг харахын тулд хаяг нь интернетээс харагддаг байх ёстой.

## Үүнийг заавал шалгана уу

`providers/qpay.js` нь QPay v2 merchant API-ийн нийтлэг бүтцээр бичигдсэн. Бодит QPay-тэй би холбогдож туршаагүй. Үйлдвэрлэлд гаргахаас өмнө sandbox дээр 1 захиалга төлж, `providers/qpay.js` доторх талбарын нэрсийг (`invoice_id`, `qr_image`, `urls`, `payment_status`, `payment_amount`) QPay-н танд өгсөн баримттай тулгана. Зөрөх талбар байвал зөвхөн энэ нэг файлыг засна. Хэрэв QPay-н callback хаягийн загвар танай гэрээнд өөр бол `createInvoice` доторх `callback_url`-ийг засна.

## Захиалга харах

```
curl -H "x-admin-key: ТАНЫ_КЛЮЧ" https://таны-домэйн.mn/api/admin/orders
```

Нийт орлого, сүүлийн 500 захиалга (хэнд, хэнээс, төлөв, дүн) гарна.

## Аюулгүй байдал

- Төлбөрийг зөвхөн QPay-ээс лавлаж баталгаажуулдаг. Хуурамч callback нөлөөлөхгүй.
- Картын дизайн, текстийг сервер дээр дахин шалгадаг. Үнийг зөвхөн сервер тогтооно.
- Төлөгдөөгүй карт харагдахгүй. Картын холбоос 32 тэмдэгтийн санамсаргүй код тул таах боломжгүй.
- Захиалга үүсгэхийг IP-ээр хязгаарласан (10 минутад 10).
- Нууц түлхүүрүүдийг хэзээ ч GitHub руу оруулахгүй, зөвхөн хостингийн орчны хувьсагчид хадгална.

## Хязгаарлалт

- Захиалгыг JSON файлд хадгалдаг. Эхний хэдэн мянган захиалгад хангалттай. Их ачаалалтай болбол `store.js`-ийг SQLite эсвэл Postgres-ээр солино (4 функцтэй).
- Карт бүрт 3 хүртэл зураг оруулна (браузер дээр автоматаар жижигрүүлж JPG болгоно, сервер дахин шалгана). Зургууд `DATA_FILE`-ийн хажуугийн `media/` хавтсанд хадгалагдах тул тэр дискийг нөөцлөөрэй. Бичлэг энэ хувилбарт орсонгүй, учир нь том файл хадгалах тусдаа сан (S3 гэх мэт) хэрэгтэй.
- Буцаан олголт, нэхэмжлэх (НӨАТ-ын е-баримт) энд хийгдээгүй. Бизнесийн бүртгэлийн дагуу тусад нь шийднэ.
- Хууль, татварын асуудлаар мэргэжлийн хүнтэй зөвлөлдөнө үү.
